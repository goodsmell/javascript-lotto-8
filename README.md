# 로또 발매기

## 🗣️ 프로그램 설명

- 로또 번호 6개 자동 발매기 입니다.
- 1000원에 1장 발급 가능합니다.
- 당첨 번호와 보너스 번호를 입력하면 **당첨 통계와 수익률(%)**을 계산해줍니다.

  > 🏆 당첨금
  > </br>
  > 1등: `6개` 번호 일치 / `2,000,000,000원` </br>
  > 2등: `5개` 번호 + `보너스 번호` 일치 / `30,000,000원`</br>
  > 3등: `5개` 번호 일치 / `1,500,000원`</br>
  > 4등: `4개` 번호 일치 / `50,000원`</br>
  > 5등: `3개` 번호 일치 / `5,000원`

## 🙏🏻 사용자 이용 규칙

1. 구입 금액을 입력하세요.
   - 1000원 단위로 입력 가능합니다
   - 1000원에 1장 발급 가능합니다.
2. 당첨 번호를 입력하세요.
   - 1~45 사이의 숫자를 ,로 구분하여 6개 입력해주세요
   - 중복 숫자는 포함할 수 없습니다.
3. 보너스 번호를 입력하세요.
   - 1~45 사이 정수 1개, 당첨 번호와 중복 불가
4. 당첨 결과를 확인해 주세요.
   - 수익률(%) 계산 방식 : (수익금 / 원금) \* 100

## ✨ 기능 구현 목록

- [x] 구입급액을 입력받는다.
- [x] 입력받은 구입금액을 검증한다
  - [x] 숫자인가?
  - [x] 1000원 단위인가?
- [x] 로또 번호 6개를 랜덤으로 발급한다.
  - [x] 1~45 사이의 중복없는 수 6개
  - [x] 오름차순 정렬
- [x] (원금 / 1000)장의 로또를 생성한다.
- [x] 생성된 로또 n개를 출력한다.
- [x] 당첨 번호를 입력받는다.
- [x] ,로 구분하여 당첨 번호를 추출한다.
- [x] 당첨 번호를 검증한다
  - [x] 6개 인가?
  - [x] 1 ~ 45 사이의 숫자인가?
  - [x] 중복은 없는가?
- [x] 보너스 번호를 입력받는다
- [x] 보너스 번호를 검증한다
  - [x] 숫자인가?
  - [x] 정수인가?
  - [x] 1~45 사이인가?
  - [x] 당첨번호와 중복되지 않았는가?
- [x] 당첨번호와 로또 번호를 비교하여 일치하는 개수를 게산한다.
- [x] 보너스번호와 로또 번호를 비교한다 일치하는 수가 있는지 확인한다.
- [x] 당첨번호 일치개수 + 보너스 번호 일치 여부로 등수를 확인한다.
- [x] 구매한 모든 로또의 등수를 확인한다.
- [x] 수익률을 계산한다.
- [x] 당첨 통계를 출력한다.

## 프로젝트 구조

```bash
src/
├─ model/
│  ├─ Lotto.js                 # 단일 로또(숫자 6개) 모델 + 자체 검증
│  ├─ WinningLotto.js          # 당첨 번호/보너스 + 매칭 로직
│  └─ PurchaseAmount.js        # 금액 검증 + 로또 장수 계산
├─ service/
│  ├─ LottoGameManager.js      # 입력 파싱·모델 생성·흐름 오케스트레이션
│  ├─ LottoTicketGenerator.js  # 무작위 로또 생성
│  └─ LottoResultCalculator.js # 당첨 통계/수익률 계산
├─ view/
│  ├─ Input.js                 # 사용자 입력
│  └─ Output.js                # 결과 출력
├─ constants/
│  ├─ game.js                  # LOTTO_CONFIG, INPUT_DELIMITER 등
│  ├─ messages.js              # 오류/문구 메시지
│  └─ prize.js                 # RANK_INFO(등수 규칙/보너스/상금)
├─ App.js                      # 컨트롤러: 실행 흐름, 재시도 래퍼
└─ index.js                    # 엔트리 포인트

```
